# PS4Control 0.2.0

- **New: in-game settings GUI** — `/ps4control` (or `/ps4control menu`), or bind
  "Open PS4Control menu" in Options → Controls (Key Mappings → PS4Control)
- Controller picker for setups with **multiple controllers plugged in**: cycle
  "Controller: Auto / pad 1 / pad 2" and watch the live stick/button readout to
  identify each pad — fixes instances grabbing the wrong controller
- Look sensitivity, cursor speed, deadzone sliders; enable + invert-Y toggles;
  all changes save instantly
- Live input panel showing bound pad, stick positions and pressed buttons
